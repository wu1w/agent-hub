- 清空 token 并用 Cmd+S 保存；刷新后再次显示，token 仍为空，没有恢复旧值。
- 再次标记 credential → 显示 → 隐藏 → 保存；掩码保持，磁盘核对 custom secret 属性仍为 true。

## 本次真实验收发现并修复

索引刷新接口返回 503 时，页面虽然提示暂停，旧会话、源路径和“在终端启动目标 Agent”按钮仍然存在。后端仍拒绝访问，但界面状态与暂停提示不一致。

修复：受保护的索引、会话、交接和源路径接口收到 503 时统一清空可见记录、选中项、路径和启动控件，禁用写交接条，显示不可用状态；成功恢复后重新载入。浏览器中再次注入故障，确认旧记录与启动按钮消失、写交接条禁用；恢复后原记录重新出现。新增自动回归覆盖索引 503 清理。

修复文件：`web/app.js`。测试：`src/core/round6-regressions.test.ts`。
